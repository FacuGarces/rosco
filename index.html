EL ROSCO · Panel del conductor

RESPUESTA (solo la ves vos)—

Tocá una letra de los mini‑roscos para saltar a ella. Todo se guarda solo y se sincroniza con el overlay abierto en este mismo navegador.

Cómo se juega El Rosco

  1. Cada equipo tiene su propio rosco (Azul y Naranja), con una palabra por letra de la A a la Z incluida la Ñ. “Con la…” = la palabra empieza con esa letra; “Contiene la…” = la letra está en algún lugar de la palabra.
  2. Cada equipo tiene su propio reloj, que solo corre mientras ese equipo responde.
  3. Acierta → letra verde y sigue jugando sin frenar el reloj.
    “¡Pasapalabra!” → letra amarilla, se frena el reloj y juega el rival. La letra vuelve en la próxima vuelta.
    Falla → letra roja, suma un error, se frena el reloj y juega el rival.
  4. Se alternan hasta que cada equipo complete su rosco o se quede sin tiempo. Si uno termina, el otro sigue solo.
  5. Gana el que tiene más aciertos. Empate → gana el que tiene menos errores. Rosco completo sin errores = “bote”.

Atajos: Espacio reloj · C correcta · X incorrecta · P pasapalabra · R ver respuesta · Z deshacer · T cambiar turno.

📡 Usarlo en un stream (OBS / YouTube)

El juego tiene 3 vistas del mismo link, que se sincronizan solas:

  • Panel del conductor — botones + respuestas (no sale al aire).
  • Overlay — solo el rosco, relojes y la definición, en 1920×1080. El hueco del centro queda en verde croma para meter la cámara.
  • Pantalla — la vista para jugar presencial / proyector (esta).

Opción A — Chrome + Captura de ventana (la más simple)

  1. Abrí el panel del conductor en Chrome:
  2. Ahí tocá 📺 Abrir overlay. Se abre otra ventana con el rosco. Dejala abierta (puede quedar atrás de otras ventanas) y hacé un clic en ella una vez para activar el sonido.
  3. En OBS: + → Captura de ventana (en Mac: “Captura de pantalla de macOS” → Método: Ventana) → elegí la ventana “Rosco · Overlay”.
  4. Clic derecho en la fuente → Filtros → + → Clave de croma (color verde). El centro queda transparente.
  5. Poné tu cámara debajo del overlay en la lista de fuentes y movela/escalala para que la persona quede centrada en el círculo.
  6. Opcional, para los sonidos: + → Captura de audio de aplicación → Google Chrome.

Variantes del overlay (pegá este link en otra ventana si querés):

La segunda es “flotante”: todo el fondo verde, así el rosco queda encima de la cámara a pantalla completa.

Opción B — todo adentro de OBS, con transparencia real (sin croma)

  1. En OBS: + → Navegador, ancho 1920, alto 1080, con este link:
  2. Agregá otra fuente de Navegador con el panel del conductor (link del paso A1), y ocultala (ojito).
  3. Para manejar el juego: clic derecho sobre esa fuente oculta → Interactuar. Se abre una ventana con los botones y respuestas, y el overlay se actualiza solo.

Ojo: una fuente de navegador de OBS no comparte datos con tu Chrome. Por eso, en la opción B, panel y overlay tienen que estar los dos dentro de OBS.
